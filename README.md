# Rust Battleship 🚢

My first project in Rust. This is a graphical 2D implementation of the classic Battleship game. The player faces off against the computer on a traditional 10x10 grid.

## 🎮 Features
* Single-player gameplay (Player vs. Computer).
* Graphical user interface with a pixel-art background.
* Intuitive ship placement system on the grid (with the ability to rotate ships using the `R` key).

## 🛠️ Technologies
* Rust
* Cargo
* macroquad

## 🚀 How to run locally
1. Make sure you have Rust and Cargo installed.
2. Clone this repository: 
   ```bash
   git clone https://github.com/Arch1e99/Project-Rust_battleship.git
   cd Project-Rust_battleship
   cargo run
   ```
